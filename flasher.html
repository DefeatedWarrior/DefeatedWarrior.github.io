Flasher

Install firmware on a board and set it up from this page, over USB. Use Chrome or Edge on a desktop or laptop; there is nothing else to install.

Ghostlight NodeArt-Net and sACN to DMX512 / RDM, for ESP32 and ESP32-S3 boards
Loading the firmware list…

Installing erases the board. Everything stored on it is wiped: network and Wi-Fi settings, ports, universes and scenes. To update a node and keep its settings, use the update file instead.

1

Pick your board

Firmware for the wrong board may not start, or may start with the wrong pins. The board list says which is which.

2

Plug it in

Use a USB cable that carries data; some cables only charge.

If no port shows up in the next step: on an ESP32-S3 dev board, try its other USB socket, or hold BOOT while you plug the cable in. An ESP32 DevKitC may need the CP210x or CH340 USB driver for your computer.

3

Install

Click Install, choose the board's port in the box the browser opens, and confirm. It takes a minute or two; don't unplug the board until it says it's done.

This browser can't install firmware. Open this page in Chrome or Edge on a desktop or laptop.

Installing only works over https.

After installing

Close the install window and leave the cable in. Then set the node up over USB: its name, admin password, Wi-Fi network and DMX universes, without joining its Wi-Fi first.

Or set it up over the network: with an Ethernet cable plugged in, the node gets an address from your network. Without one, it opens its own Wi-Fi network, called ESP-NODE- and four letters and digits. Join it with the password 12345678 and open http://192.168.4.1.

Updating a node that already runs this firmware

Download the update file for your board, open the node's web UI, and upload it under Firmware Update. The node keeps its settings.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a desktop or laptop.

Not connected
Plug the node in over USB, click Connect and pick its port. The node needs firmware with USB setup (any release from this page).
