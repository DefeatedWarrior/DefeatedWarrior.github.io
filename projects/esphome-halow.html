What it does

An ESPHome external component that replaces wifi: with halow:. Set the SSID, password and region in YAML and the device joins a HaLow access point with full IP networking, so the Home Assistant API, OTA updates, mDNS and MQTT all work over sub-1 GHz radio with up to roughly 1 km of range.

Why HaLow over LoRa?

HaLow uses standard IP networking: TCP, UDP, DHCP, mDNS, MQTT and the ESPHome API all work natively, with no protocol translation, gateway bridges or TTN accounts. Home Assistant sees the device directly, OTA works over the same link, and bidirectional control is fast. LoRa still wins on raw range and power for simple one-way sensors; for anything needing reliable two-way communication, HaLow is cleaner.

This fork's changes

Forked from sweitzja/esphome-halow so the component builds and runs on ESPHome 2026.x, the native ESP-IDF toolchain used by the Home Assistant ESPHome Builder. Highlights from the commit history:

  • Fixed build and boot on ESPHome 2026.x.
  • Fixed Home Assistant API connections dropping on 2026.x, plus a reconnect race and a reconnect stall.
  • Added a use_address option so the Device Builder can find a device on a separate subnet, including the cached logs and upload path.
  • Static IP DNS fix and SDK download cleanup from a second review pass.
  • Reorganised the repo and added reference docs and test tools, such as a serial watcher.

Every change is listed with its reasoning in PATCHES.md, and the pre-review state is kept on the pre-improvements branch.

Quick start

external_components:
  - source: github://DefeatedWarrior/esphome-halow
    components: [halow]

halow:                       # replaces wifi:
  ssid: !secret halow_ssid
  password: !secret halow_password
  country_code: "US"         # required; must match your region and AP
  rssi:
    name: "HaLow RSSI"

Install over USB the first time; the first compile downloads the Morse Micro SDK (about 50 MB). The access point must be in AP mode with bridging enabled so Home Assistant can reach HaLow devices. See the README for the full setup.
